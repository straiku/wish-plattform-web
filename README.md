# Wishes Platform

A digital alchemy platform where text becomes sacred artifacts and collaborative desires transform into ethereal experiences.

## Overview

Wishes Platform is not your typical social media application. Inspired by "The Digital Alchemist" creative north star, this platform treats digital space as a sacred gallery for intention. Through intentional asymmetry and editorial-grade typography, we transform simple desires into prestigious artifacts.

## Key Features

- **Intentional Asymmetry**: No rigid grids or center-aligned layouts
- **Text as Art**: Typography is the primary visual texture
- **Glassmorphism Design**: Ethereal layers with smoked glass effects
- **Collaborative Remixes**: Users can layer and remix wishes
- **Weekly Top Wishes**: Editorial-style curation of desires

## Design System

Built with "The Ethereal Editorial" design system featuring:

- **Midnight Spectrum**: Deep obsidian base with iridescent highlights
- **Editorial Typography**: Newsreader serif for headlines, Manrope sans-serif for body
- **Tonal Layering**: Depth achieved through surface hierarchy, not shadows
- **Glass Components**: Floating wishes with backdrop blur effects

## Tech Stack

- **Frontend**: React + TypeScript + Vite
- **Styling**: CSS-in-JS with design tokens
- **Architecture**: Component-based with intentional asymmetry

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Design Philosophy

We move away from the "Dashboard" and the "Clone" by embracing:

- Negative space as a design element
- Asymmetric grids with staggered verticality
- Tonal transitions instead of hard borders
- Editorial prestige over typical SaaS aesthetics

## Contributing

When contributing to this platform, remember:

- Embrace negative space and asymmetric layouts
- Use tonal layering for depth, not shadows

## Development Setup

The project uses React + TypeScript + Vite for optimal development experience with hot module replacement.
